# Taxered

Податковий AI-асистент для українських інвесторів у вигляді чату. Надішліть звіт брокера чи
історію гаманця — і отримайте додаток **Ф1 (F0121215)** до декларації **F0100215** з ПДФО та
військовим збором, дохідність інвестицій з урахуванням інфляції, карту податків, спреди й комісії
або портфель Ledger: з формами, графіками та файлами PDF, Excel, XML.

## Архітектура

Агент побудований на **LangGraph.js / LangChain** з моделлю **Claude** (`@langchain/anthropic`).
Головний агент (supervisor) спілкується з користувачем і передає задачі п'ятьом субагентам —
кожен зі своїми інструментами (патерн «агенти як інструменти»):

```
                            ┌─ ask_f1_agent ──────► Ф1: XML IB / Freedom → курси НБУ → Ф1, PDF, Excel, XML ДПС
                            ├─ ask_returns_agent ─► дохідність: CSV-виписки IB → інфляція, податки, капітал
користувач ⇄ supervisor ────┼─ ask_tax_map_agent ─► карта податків: ставки 60+ країн, карта, порівняння
                            ├─ ask_spreads_agent ─► CSV Ledger Live → спреди обмінів, комісії мережі
                            └─ ask_ledger_agent ──► CSV Ledger Live → портфель, вартість, динаміка
```

- **Модель не рахує.** Усі суми рахує той самий перевірений код, що й раніше (`src/app/lib`):
  копійчана арифметика Ф1, XML за XSD ДПС, парсери брокерів, курси НБУ. Модель лише вирішує, які
  інструменти викликати, і пояснює результат.
- **Артефакти.** Інструменти віддають форми, графіки, карти й файли як кастомні події LangChain;
  сервер пересилає їх у браузер разом зі стрімом тексту (SSE). Артефакт містить вхідні дані
  розрахунку, а браузер виконує ті самі чисті функції — тож форма в чаті завжди збігається з
  цифрами агента. Ф1 можна відкрити в редагованій формі та експортувати прямо з браузера.
- **Пам'ять.** Розмову supervisor-а зберігає чекпоінтер LangGraph (`MemorySaver`) за
  `thread_id`; субагенти без стану — кожне делегування є окремою задачею. Історія лише
  доповнюється (вимога preserved thinking у Claude Opus 5.5).
- **Дані.** Файли й результати живуть лише в пам'яті сервера (до 2 годин неактивності або до
  «Нова розмова»), на диск не пишуться. Моделі передаються повідомлення та підсумки розрахунків,
  а не файли цілком.

### API чату

| Метод    | Шлях                                            | Опис                                      |
| -------- | ----------------------------------------------- | ----------------------------------------- |
| `POST`   | `/api/chat/threads/:threadId/files`             | файл у тілі, назва в `X-File-Name`        |
| `POST`   | `/api/chat/threads/:threadId/messages`          | `{ text, fileIds }` → `text/event-stream` |
| `GET`    | `/api/chat/threads/:threadId/outputs/:outputId` | згенерований файл                         |
| `DELETE` | `/api/chat/threads/:threadId`                   | забути розмову та файли                   |

Події стріму (`src/app/chat/protocol.ts`): `status` (який субагент працює), `token` (текст
відповіді), `artifact` (форма, графік, карта, файл), `error`, `done`.

### Змінні середовища

| Змінна                     | За замовчуванням  | Опис                                                          |
| -------------------------- | ----------------- | ------------------------------------------------------------- |
| `ANTHROPIC_API_KEY`        | —                 | обов'язкова; без неї чат відповідає, що агент не налаштований |
| `TAXERED_MODEL`            | `claude-opus-5-5` | модель Claude                                                 |
| `TAXERED_EFFORT`           | `medium`          | `low` … `max` — глибина міркувань моделі                      |
| `TAXERED_REFUSAL_FALLBACK` | увімкнено         | `0` вимикає серверний fallback при відмові моделі             |

## Можливості

- Ф1: позиції (акції, облігації, опціони, дивіденди, проценти, крипто), курси НБУ на дату операції,
  ПДФО 18% / 9% (дивіденди) + військовий збір 1.5% (≤2024) / 5% (≥2025), збиток минулих років,
  поріг пп. «а» 170.2.8, коди активів 1–4; позиції можна також описати словами
- Пакет XML для Електронного кабінету: декларація F0100215 + додаток Ф1 F0121215 у windows-1251 з
  взаємними `LINKED_DOCS`; кожен файл у тестах перевіряється офіційною XSD (`schemas/dps/2026`)
- Дохідність інвестицій за CSV-виписками IB: номінальна й реальна, податки, курсова різниця
- Карта податків на дивіденди, приріст капіталу та відсотки для 60+ країн
- Ledger Live: спреди обмінів, комісії мережі, портфель з живими цінами
- База знань (Markdown-статті), довідка; SSR + пререндер, PWA, світла/темна тема
- Доступність: WCAG AA

## Стек

Angular 22 (standalone, signals, zoneless, SSR), Tailwind CSS 4, Express, LangGraph.js,
LangChain, Claude, jsPDF, SheetJS, marked, Lucide.

## Команди

```bash
npm install
ANTHROPIC_API_KEY=… npm start  # dev-сервер з чатом: http://localhost:4200
npm run build             # production-збірка в dist/Taxered (з пререндером)
npm run serve:ssr:Taxered # запуск зібраного SSR-сервера (PORT, за замовчуванням 4000)
npm test                  # unit-тести (Vitest) + перевірка XML за XSD ДПС (потрібен xmllint);
                          # агенти тестуються наскрізно зі сценарними моделями, без API-ключа
```

`xmllint` є в macOS; у Debian/Ubuntu — `sudo apt-get install libxml2-utils`.

## Структура

```
src/
  agent/           # сервер агента: граф LangGraph (graph.ts), субагенти та їх інструменти (agents/),
                   # модель Claude (model.ts), HTTP/SSE API (http.ts), сесії в пам'яті (session.ts)
  app/
    chat/          # сторінка чату, сервіс стріму, протокол, віджети артефактів (artifacts/)
    widgets/       # графіки, карта світу, портфель Ledger — рендеряться у відповідях чату
    declaration/   # редагована форма Ф1 і чиста логіка розрахунку (tax-model.ts)
    lib/           # незалежні від фреймворку модулі: парсери брокерів, Ф1/XML ДПС, дохідність,
                   # ставки країн, Ledger, PDF, Excel, курси НБУ
    pages/         # база знань, довідка, про проєкт, юридичні сторінки, 404
    core/ layout/ shared/
  content/articles # статті бази знань (Markdown з front matter, вбудовуються під час збірки)
  server.ts        # Express: API чату, заголовки безпеки (CSP тощо), редиректи, sitemap.xml
schemas/dps/       # офіційні XSD і бланки ДПС
```

Колишні сторінки `/uk-ua/calculator`, `/uk-ua/tax-map`, `/uk-ua/ledger` перенаправляють (301) у
чат з відповідною підказкою (`?topic=…`).

Щоб додати статтю, покладіть `uk-ua-<slug>.md` у `src/content/articles` — вона підхопиться під час
збірки (`scripts/build-articles.mjs`).

## Деплой

`Dockerfile` збирає застосунок і запускає самодостатній SSR-бандл (`node dist/Taxered/server/server.mjs`,
порт 3000). GitHub Actions (`.github/workflows/deploy.yml`) публікує образ у GHCR при пуші в `master`;
`terraform/` описує сервіс Cloud Run: ключ Anthropic береться з Secret Manager
(`anthropic_api_key_secret`), а `session_affinity` тримає браузер на інстансі, у пам'яті якого
його розмова (стан чату не спільний між інстансами).

Дозволені хости для SSR задаються в `angular.json` → `security.allowedHosts`
(`taxered.stackthrow.com`, `*.run.app`, `localhost`).
